## Overview

This project is a frontend dashboard for managing developer applications and inspecting their logs. It focuses on real-time UI updates, optimistic interactions, and a minimal but scalable state architecture using Angular Signals.

View the live demo [here](https://timber-logging-dashboard.netlify.app/)

## Features

- User authentication using HttpOnly cookies
- Protected dashboard routes using Angular route guards
- Global error handling with Angular HTTP interceptors
- Secure API communication between frontend and backend
- Optimistic UI updates for fast interactions
- Simple log viewing dashboard UI
- Environment-based API configuration

## Tech Stack

- Angular 19
- Angular Signals
- RxJS
- HttpClient
- Reactive Forms
- TypeScript
